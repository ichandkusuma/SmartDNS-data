# SmartDNS-data

Public data repository for [SmartDNS](https://github.com/ichandkusuma/SmartDNS).

## Available Data

### `domains_isp`

Validated and normalized domain blacklist data used by SmartDNS.

The dataset is processed from TrustPositif sources and validated against official IANA TLD data before publication.
